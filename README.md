# Link-in-bio card

**Create a profile:** open `index.html` (or `/` once deployed), fill in the form
— name, contact info, and links — then click **Preview profile**.

**Preview:** shows exactly how the page will look. Use **Edit** to go back and
change anything, or **Get live link** to open the final public page. All
profile data is packed into that page's URL (after the `#`) — nothing is
stored on a server, so the link itself *is* the saved profile. Bookmark or
share it to keep access.

**Deploy to Vercel:** push this folder to a Git repo and import it in Vercel
— no build command or config needed, it deploys as-is.

**No accents, colors, or links to change in code** — everything is set from
the form on `index.html`.
